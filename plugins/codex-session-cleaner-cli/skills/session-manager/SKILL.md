# Codex 会话管理（命令行版）

当用户要求查看、整理、归档或删除 Codex 会话时使用本插件。本版本面向 Codex CLI，
没有可视化管理页；桌面客户端请改用 `codex-session-cleaner`。

1. 用户表达整理、归档或删除意图时（包括仅说明“清理会话”“打开会话管理器”），
   **直接调用 `select_sessions`**，由用户在交互表单中依次完成筛选、选择会话和选定操作；
   不要先返回文本清单再等待用户报出会话编号。
2. `select_sessions` 返回的 `interactive.performed` 表示归档或删除已由用户在表单中确认并执行完毕，
   只需如实转述结果，不要再调用 `archive_sessions` 或 `delete_sessions` 重复执行。
3. 用户只想查看会话或文件线索时，调用 `list_sessions` 和 `inspect_session_files`，不要弹出表单。
4. 不得替用户猜测归档或删除目标，也不得绕过当前会话保护。
5. 说明清楚：删除的是 Codex 持久化会话及其派生会话，不会删除项目文件，
   也不会清理跨会话共享的插件缓存、模型缓存或凭据。
6. 标记为“隐藏分叉”的会话虽然不在 Codex 常规列表中，但仍可能引用并阻止源会话删除。
   必须让用户自己选择该分叉；若分叉与源会话同时选中，插件会按分叉在前、源会话在后的顺序删除。
7. 用户需要脱离对话直接在终端中操作时，告知运行插件目录下的 `scripts/launch_tui.sh`。
8. 会话标记为「使用中」时，说明它正被其他 Codex 进程持有，只能在 Codex 侧边栏中归档或删除，
   不要反复重试。
