# Codex 会话管理

当用户要求查看、整理、归档或删除 Codex 会话时使用本插件。

1. 先调用 `open_session_manager`。
   - 客户端渲染出管理页时，让用户在页面中勾选并操作。
   - 返回的是文本会话列表时，说明当前客户端无法渲染管理页组件。本插件不提供交互表单，
     应告知用户改用命令行版插件 `codex-session-cleaner-cli`。
   - 会话标记为「使用中」时，说明它正被其他 Codex 进程持有，只能在 Codex 侧边栏中归档或删除。
2. 用户只想查找项目或文件时，可调用 `list_sessions` 和 `inspect_session_files`。
   `list_sessions` 支持按类别标签筛选，也支持按最后更新时间筛选 1 天内、1 周内、1 个月内、3 个月前、1 个月前、1 周前，或传入自定义开始/结束日期。
3. 永久删除必须由用户在管理页中选择会话；中文界面输入精确确认词 `删除`，英文界面输入 `delete`。
   本插件不提供交互表单；在无管理页的客户端上，应告知用户改用命令行版插件 `codex-session-cleaner-cli`，不要代替用户确认删除。
4. 不得替用户猜测删除目标，也不得绕过当前会话保护。
5. 说明清楚：删除的是 Codex 持久化会话及其派生会话，不会删除项目文件，也不会清理跨会话共享的插件缓存、模型缓存或凭据。
6. 永久删除成功后插件会同步桌面侧边栏；若页面提示同步失败，告知用户刷新或重启 Codex，不要再次删除同一会话。
7. 用户希望留在终端、不打开桌面端管理页时，告知改装命令行版插件 `codex-session-cleaner-cli`（`codex plugin add codex-session-cleaner-cli@codex-plugins`），它提供交互表单和终端界面；本版不含终端界面。
8. 标记为“隐藏分叉”的会话虽然不在 Codex 常规列表中，但仍可能引用并阻止源会话删除。必须让用户选择该分叉；若分叉与源会话同时选择，按分叉在前、源会话在后的顺序删除。不得仅因存在引用就自动扩大删除目标。
