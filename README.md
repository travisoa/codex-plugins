# Codex 会话清理器

一个本地 Codex 插件，通过 MCP Apps 管理页调用 Codex `app-server`：

- 按当前、已归档、全部会话浏览和搜索；
- 按最后更新时间筛选 3 个月前、1 个月前、1 周前的会话，或使用自定义日期范围；
- 显示项目目录、Git 分支、状态和派生会话数量；
- 从会话记录中提取“修改文件”和“命令引用文件”线索；
- 批量归档；
- 输入 `永久删除` 后批量删除，并拒绝删除当前管理会话。
- 删除成功后同步 Codex 桌面侧边栏，避免保留无法打开的历史条目。

## 安全边界

- 永久删除只调用官方 `thread/delete`，不会删除项目文件。
- 官方删除成功后，插件仅按已删除的精确会话 ID 清理桌面本地目录项，并通过桌面 IPC 刷新窗口；若桌面内部结构不兼容会停止同步并提示刷新或重启，不影响官方删除结果。
- 当前管理会话和临时会话不可删除。
- 后端要求确认词、当前会话元数据及非空会话 ID；仅靠前端按钮不能绕过校验。
- 文件列表是从会话记录提取的线索，不代表项目中的完整文件集合。
- 插件不会清理跨会话共享的插件缓存、模型缓存、认证信息或全局配置。

## 本地开发

```bash
python3 -m unittest discover -s tests -v
python3 -m compileall server tests
```

也可以直接启动 MCP 服务器：

```bash
./scripts/launch_server.sh
```

服务器使用逐行 JSON-RPC（stdio），只依赖 Python 标准库。
